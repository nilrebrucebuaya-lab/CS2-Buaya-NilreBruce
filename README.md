# Travel Fare Calculator

## Description
A Travel Fare Calculator calculates the total amount of your travel fare depending on kilometer travel and amount of passengers.

## Version 1 – Original code without input validation
- Input: Accepts a name, the distance and amount of passengers
- Process: Multiplies the distance, fare rate (14) and amount of passengers to get the total fare
- Output: Total Fare
- Does not include input validation.

## Version 2 - Updated Code with Input Validation
- Input: You input a name, distance, and amount of passengers.
- Process: Checks the name if it isn't empty, checks the distance if it isn't <= 0, checks the amount of passengers if it isn't <= 0 and finally multiplies the distance, fare rate (14) and amount of passengers to get the total fare.
- Output: Total Fare
- Includes Input Validation
