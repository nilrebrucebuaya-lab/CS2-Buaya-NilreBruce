# Travel Fare Calculator

## Description
A Travel Fare Calculator calculates the total amount of your travel fare depending on kilometer travel and amount of passengers.

## Version 1 – Original code without input validation
- Input: Accepts a name, the distance and amount of passengers
- Process: Multiplies the distance, fare rate (14) and amount of passengers to get the total fare
- Output: Total Fare
- Does not include input validation.
